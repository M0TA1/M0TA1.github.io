拖了很久，终于写下第二篇，距离上一篇已经过了大半年。

老实讲，这个 Blog 是临时抱佛脚，为了面试学校里 ITSO 的后端实习岗位而做的。很明显，带着这个不成熟的博客，当时没什么项目经历的我并没有通过面试。

当时跟着视频教程做这个东西，好像花了我一整天吧，页面什么的还没能做得很好看。这次用 Codex 重新完善它，也就花了一个晚上，并且我几乎只需要用自然语言描述需求，剩下的就是坐等它自己完成，给我返回结果。

细想起来挺震惊的。那时还是一月份，后来被称为 OpenClaw 的项目刚开始走红。到了三月，“全民养🦞”的热潮席卷而来。如今 OpenClaw 虽已淡出大众视野，但它推动的 Agent 浪潮也仍对我们有着深远的影响。

早期的 Codex 我也用过，当时就是绑定了一下 GitHub 账号，也不知道后面有什么用，就没有继续深入。Claude Code 也早已在程序员圈内出名，却并没有像小龙虾那样为大众所熟知。

也许是看到了更多应用场景，各大厂商加快跟进，开发自己的 Agent 和 Harness。感觉大模型开始更大规模地落地了。

站在当下，以我浅薄的眼光来看，很难说这是好事还是坏事。但是我们唯一可知的是，飞轮已经启动了。
